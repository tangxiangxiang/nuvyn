# 消费结构分析

## 适用场景

用户想了解消费构成、支出变化、重复消费或优化空间。

## 分析方法

- 获取目标期间的支出汇总和主要分类。
- 先找对总体金额影响最大的分类，再根据问题查看重复商户或交易明细。
- 需要判断变化时，选择统计口径一致的历史期间比较。
- 区分账本事实和对消费用途的推测；缺少用途信息时向用户询问。

## 账本口径

大额支出不必然浪费，分类名称也不能证明消费是否必要。少量交易样本不能代表全部支出。避免道德评价，尊重用户实际生活需求和偏好。

## 回答建议

指出主要消费来源、值得关注的变化和可选择的调整方式；建议应具体且容易执行，不把推测写成事实。
