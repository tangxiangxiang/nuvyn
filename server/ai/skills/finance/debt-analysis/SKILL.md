# 债务分析

## 适用场景

用户询问债务压力、还款记录、利息成本或提前还款选择。

## 分析方法

- 查询相关还款统计，并区分还款本金、利息和优惠。
- 解释还款对当期现金流的影响；必要时结合余额与收入稳定性。
- 比较方案前先确认利率、剩余期限、费用和用户的流动性需求。
- 将账本已记录的事实、用户补充的信息和假设分别说明。

## 账本口径

还款本金不是普通消费，但会形成资金流出并减少负债。账户余额不等于贷款剩余本金。有限还款记录不能证明贷款合同条件；不得编造利率、期限或提前还款费用。

## 回答建议

说明债务结构、还款压力、利息影响和方案利弊。若缺少合同信息，应明确指出缺失条件，不自行创建计算引擎或给出确定性结论。
