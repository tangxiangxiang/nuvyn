# 现金流分析

## 适用场景

用户想了解资金流入流出、储蓄能力或为什么难以积累储蓄。

## 分析方法

- 查询指定期间的收支和结余，留意收入稳定性、普通消费、还款本金及净利息。
- 只有问题需要时，再查提现、转账、调整、排除统计的交易或账户余额变化。
- 比较期间时统一起止范围和统计口径；区分统计汇总与实际账户资金变化。

## 账本口径

转账通常不代表整体资产增加或减少；提现不自动等同于消费。已计入支出的费用不可重复扣减。Statistics Exclusion 会使统计结果与实际资金流动不同。缺少期初资产或完整资金流证据时，不宣称精确的实际储蓄额。

## 回答建议

解释主要流入、流出和资金压力，指出最值得关注的因素，并说明结论的证据范围。
