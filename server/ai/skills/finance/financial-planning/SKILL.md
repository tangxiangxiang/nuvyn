# 财务规划

## 适用场景

用户需要预算、储蓄目标或多个财务选择的情景分析。

## 分析方法

- 先理解用户当前目标、时间范围、限制和优先级，并参考相关 Finance Memory。
- 查询规划所需的最新账本数据；把账本事实、用户计划与情景假设分开。
- 根据应急资金、固定支出、债务义务和流动性需求比较少量可行方案。
- 如果关键条件不足，先询问或明确列出假设。

## 账本口径

当前用户表达优先于旧记忆。历史预算目标不等于当前收入，情景结果不代表未来必然发生。不得编造未来收入、利率或投资收益，也不承诺投资回报。

## 回答建议

给出可执行的阶段性选择、关键假设和主要风险，保留用户自主决定权，不替用户作出不可逆财务决定。
