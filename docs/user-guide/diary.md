# Diary

Open **Diary** from the top navigation and unlock it with your Diary password.
Diary content stays private while locked. Its calendar and search results are
available after unlock.

## Calendar and daily entries

The calendar shows each day's mood and indicates when it has text or
attachments. Select a date to open its entry. Today and past dates can be
edited; future dates are read-only.

In reading mode, a day can contain a mood, bullet entries, photos and PDF
files. Select **Edit** to change it. Use the mood control to choose or clear
the day's mood. Each bullet is a separate entry. Press Enter in an entry to
split it and start another bullet. Use an entry's **…** menu to add a photo
there or remove that entry; use the header's **…** menu to add a new entry.

To attach a photo to a specific entry, open that entry's **…** menu and choose
**添加图片**. To add photos or PDFs to the end of the day, choose **添加附件**
from the header menu. End-of-day photos are not linked to an entry. Image
groups keep their order and show up to nine photos each; PDFs remain separate
file cards. Open a photo to preview it. Use its **…** menu to move it after
another entry, move it to the end, or remove it. Select a PDF to download it.

Diary uses manual saving. In edit mode, choose **保存日记** from the header's
**…** menu. The same menu contains **删除日记** for a saved day and asks for
confirmation before deletion. Closing or cancelling with unsaved changes
prompts you to keep editing or discard them.

## Search

Open global search and enter text from a daily entry or an exact date such as
`2026-11-15`. Select a result to open that day; a text result takes you to the
matching entry. Diary search requires the Diary to be unlocked.

## Life events and countdowns

Use the Diary/Events control in the top navigation to switch to life events.
The calendar keeps its month while you switch views. Select a date to view,
add or edit events. Events can span several days, include times, repeat
annually and appear in the countdown list. Mark an event as primary to
prioritize its emoji on the calendar.

The countdown list shows the three nearest upcoming events by default. Select
an item to open it. An annual February 29 event falls on February 28 in
non-leap years. Countdown uses calendar days in your local time zone.
