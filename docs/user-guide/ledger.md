# Ledger

> [!IMPORTANT]
> 这是 Ledger 当前用户指南，描述已提交实现中的用户行为。若本文与运行时行为发生偏差，以代码和 [Ledger Architecture](../architecture/ledger.md) 为准；旧 PRD 只保留设计沿革。

## Ledger 是什么

Ledger 是 Nuvyn Personal OS 中负责个人财务事件的一级 Workspace，用来回答“我现在有多少钱、欠多少钱、钱放在哪里，以及最近发生了什么”。它和其他核心 Workspace 的分工是：

~~~text
Note   → 我知道什么
Diary  → 我经历了什么
Ledger → 我的钱发生了什么
Board  → 我正在思考和构思什么
~~~

Ledger 不是银行聚合器，也不是专业会计系统。四个 Workspace 仍然属于同一个 owner 的 Personal OS；Ledger 只负责财务领域的专业体验。

## 进入 Ledger

当前入口是：

- /ledger：财务概览。
- /ledger/transactions：交易记录。
- /ledger/accounts：账户管理。
- /ledger/accounts/:id：账户详情。

旧的 /bills 和 /bills/transactions 只保留兼容重定向，会分别转到概览和交易记录，不是新的产品名称。

## 首次设置

第一次进入时依次完成：

1. 选择基础货币。
2. 选择 Ledger 使用的 IANA 时区。
3. 创建第一个账户。

第一个账户成功创建后，系统将 hasCreatedAccount 设为 true，基础货币和时区进入生命周期锁定状态；账户图标偏好仍可维护。金额按基础货币的小数位保存和显示。

## 账户

账户性质只有两种：

- asset（资产）：我拥有或控制的资金。
- liability（负债）：我需要偿还的债务。

账户类型包括现金、银行账户、钱包、信用卡、贷款和其他。现金、银行账户、钱包固定为资产；信用卡、贷款固定为负债；“其他”可以选择性质。

账户支持名称、性质、类型、图标、卡号、期初余额、期初日期和备注。当前余额由期初余额和有效交易实时投影得出，不是手工填写的字段。账户有交易历史后，性质、类型、期初余额和期初日期不能修改；账户资料字段仍按表单允许调整。卡号是可选资料，现金、钱包、银行等账户都可以不填写；已有卡号仍会保留，并在详情中脱敏显示。

账户当前余额必须为 0 才能归档。归档账户仍可查看并可恢复，不能用于新的财务操作；有历史记录的账户不能永久删除。交易详情中若关联了归档账户，恢复账户后才能修改财务字段或删除交易。

账户图标提供通用图标、中国主要银行、微信、支付宝、云闪付和自定义图标；自定义图标只改变展示，不改变账户语义。

## 分类

设置中的分类按“收入分类”和“支出分类”分组。自定义分类可以创建、修改名称、替换图标和移入回收站；分类名称在同一收支方向内不能重复。分类图标支持内置图标，也支持上传合法 SVG（不超过 256 KB 且不能包含脚本）。内置默认分类均受保护，不能重命名、改方向或删除。

默认分类按常用程度保持扁平排列。收入分类为：工资、奖金、兼职、投资收益、红包 / 礼金、退款和其他；支出分类为：餐饮、交通、购物、日用、住房、通讯、订阅、娱乐、医疗、教育、旅行、人情往来、保险、利息、手续费和其他。利息与手续费是受保护的系统分类。

删除没有交易历史的自定义分类时，分类会先移入“回收站”；回收站可恢复分类，也可永久删除。已有交易记录的分类不能删除，服务端会拒绝将其移入回收站或永久删除，以保留历史记录完整性。

“利息”和“手续费”是受保护的支出系统分类。它们由还款和提现组合交易自动使用，不能按普通分类重命名、归档或删除；还款表单不要求用户再次选择“利息分类”。

## 记录一笔交易

顶层交易类型保持为：

- 收入：金额、账户、收入分类、发生时间、地点、交易对象和备注。
- 支出：金额、账户、支出分类、发生时间、地点、交易对象和备注。
- 转账：在两个账户之间移动资金。

### 转账子类型

转账内部有三个业务子类型，但它们不是新的顶层交易类型：

- **普通转账**：资产或负债账户之间的资金移动，不计入收入或支出。
- **还款**：资产账户 → 负债账户。表单中的本金是转账本金；可选利息会自动作为“利息”支出计入收支。
- **提现**：资产账户 → 资产账户。表单中的提现金额是资金移动金额；可选手续费会自动作为“手续费”支出计入收支。

还款例如本金 ¥5,000、利息 ¥300：资产账户减少 ¥5,300，负债减少 ¥5,000，本期支出增加 ¥300。提现例如提现金额 ¥2,000、手续费 ¥2：

- 额外扣除：转出减少 ¥2,002，转入增加 ¥2,000，支出 ¥2。
- 从提现金额中扣除：转出减少 ¥2,000，转入增加 ¥1,998，支出 ¥2。

因此利息和手续费不会被偷偷加进转账本金。新建提现默认选择“从提现金额中扣除”；用户也可以改为“额外扣除”。

## 交易记录

交易记录以桌面数据表格呈现，列为：交易对象、类型、分类、账户、备注、时间和金额。还款、提现在类型列显示为转账的展示标签，分别显示“还款”和“提现”。

可按类型、账户、分类、日期和搜索条件筛选。日期支持全部、今天、本周、本月、今年和自定义范围；时间按 Ledger 时区解释，表格显示完整年份和时间。列表使用服务端分页，当前 UI 提供 5、25、50、100 条/页，不是无限滚动。

## 交易详情、编辑与删除

点击交易行可打开详情。普通收入、支出和转账可以编辑；删除是软删除，删除后不会再参与余额和汇总，也没有普通恢复入口。余额调整由账户调整流程维护，在交易详情中只读。

还款或提现的利息/手续费会作为真实的支出记录出现在交易列表中。例如列表可以同时出现“微信零钱提现手续费 -¥1”和“微信零钱 → 招商银行储蓄卡 ¥99”。它们可以按支出、手续费 / 利息分类、账户和搜索条件筛选；但 companion Expense 不是一笔可独立编辑或删除的业务对象，修改或删除应通过对应的还款 / 提现组合操作完成。

交易对象中的“微信零钱提现手续费”和“花呗还款利息”是在交易发生时保存的历史名称，不是页面临时拼出来的文字。账户之后改名，不会自动修改历史手续费或利息名称。

搜索会匹配交易对象、地点、备注和关联账户名称。例如搜索“微信”可以命中“微信零钱 → 招商银行储蓄卡”转账，也可以命中“微信零钱提现手续费”；搜索“招商”可以命中该转账，搜索“手续费”可以命中手续费支出。

账户名称修改后，普通转账展示使用当前账户名称，例如“微信零钱 → 招商银行”可能变成“微信钱包 → 招商银行”；历史手续费 / 利息交易对象仍保持交易发生时的快照。这是有意设计，不是数据显示不一致。

## 财务概览

概览展示总资产、总负债、净资产、收支、账户、分类分析、最近交易、期间摘要和趋势。期间导航支持今天、本周、本月和今年，也支持以过去日期为锚点查看对应期间；趋势展示锚点所在的连续 12 个日历月。转账本金不进入收支统计，利息和手续费支出会进入支出及分类统计。

## 数据持久化与恢复

Ledger 记录持久化在 SQLite；余额、收支和图表数据都可由有效记录重新投影。新建设置、账户、分类和交易时，客户端会保存待确认意图并使用同一个幂等键重试；当请求结果不明确时，Ledger 会先要求恢复或确认，避免重复记账。页面刷新或服务重新启动后，已落库数据仍由服务端重新计算。
