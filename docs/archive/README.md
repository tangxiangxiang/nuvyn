# Documentation Archive

This directory preserves design proposals, implementation plans, completion evidence, audit snapshots, and temporary freeze records. It exists for traceability, not as the source of truth for current Nuvyn runtime behavior.

These files are historical records. Their dates, old commit SHAs, and stored
identifiers are evidence of earlier work and do not represent the current
Nuvyn runtime authority.

## Collections

- [`plans/`](plans/) — dated implementation plans.
- [`specs/`](specs/) — dated designs and feature specifications.
- [`implementation-records/`](implementation-records/) — point-in-time implementation and audit records.
- [`closures/`](closures/) — final closure and verification evidence.
- [`freezes/`](freezes/) — temporary scope freezes and deferred backlogs.

## Reading archived documents

Archived documents retain their original date and terminology. File paths, component names, requirements, and conclusions may no longer match the current codebase. A statement in this directory must not override maintained documentation or code.

Use the [Documentation Hub](../README.md) for current user, deployment, architecture, development, and design guides.

## Maintenance policy

- Do not silently rewrite historical conclusions to match later behavior.
- Fix broken repository links or add a short archival note when needed for navigation.
- Add new material here only when it has enduring traceability value.
- Prefer a maintained canonical page for current behavior; link from the archived record when readers could otherwise be misled.
