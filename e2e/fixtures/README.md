# Browser test fixtures

## `excalidraw-note-image.svg`

The diagram in this fixture was authored specifically for Nuvyn tests and
exported with the repository-locked `@excalidraw/excalidraw@0.18.0-4e758db`
package. It contains a rectangle, arrow/path, bilingual text, clipping, a
local embedded PNG symbol, and the font data emitted by the real exporter.
It does not contain user artwork or data.
